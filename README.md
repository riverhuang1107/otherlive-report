# 专线在售线路运营分析报告生成器

读取放置在项目根目录下的 `otherlive-线路汇总.xlsx` 或 `otherlive-线路汇总.csv`，生成相同口径的专线财务和产品运营分析报告。

## 使用方法

```powershell
python report_generator.py
```

指定输入文件、输出目录和统计基准日：

```powershell
python report_generator.py `
  --input .\otherlive-线路汇总.xlsx `
  --output-root .\reports `
  --as-of 2026-08-11
```

CSV 文件使用同一套字段和分析逻辑，直接将输入文件替换为 CSV 即可：

```powershell
python report_generator.py `
  --input .\otherlive-线路汇总.csv `
  --output-root .\reports `
  --as-of 2026-08-25
```

CSV 支持 UTF-8（含 BOM）和 GB18030 编码；末尾多余的空列会自动忽略。

真实业务源文件和生成的 `reports/` 报告包含业务数据，已通过 `.gitignore` 排除，不同步到代码远端仓库。克隆代码后，请自行将输入文件放入项目目录再运行；自动化测试使用 `tests/fixtures/` 下的虚构样例数据，不依赖真实业务文件。

每次运行都会创建新的目录，例如：

```text
reports/20260811_153000_a1b2c3d4/
├── 专线运营分析报告_20260811_a1b2c3d4.html
└── 专线运营分析报告_20260811_a1b2c3d4.md
```

报告金额按人民币元展示。7 天内到期口径为结束日期落在统计基准日到其后 7 个自然日之间，包含边界日期。

## 测试

```powershell
python -m unittest -v
```

运行时需要 Python 3.10+ 和 `openpyxl`。

线路状态按统计基准日计算：结束时间早于统计基准日的线路标记为“已回收”，其余为“在售”。报告的全量财务、平台、地域、付款周期和创建月份统计保留已回收线路，并提供状态拆分。

报告在“7 天内到期线路提醒”之后展示“每月在售总带宽”柱状图。该指标采用月末快照口径，从最早服务月份展示到统计基准日所在月份；当前月以统计基准日作为快照日期，快照日尚未开始或已经结束的线路不计入。

金额口径中，`销售价格`表示合同销售额，`结算价格`表示公司实际收入；报告会在 KPI、状态、平台、地域、付款周期、创建月份和到期提醒中分别展示实际收入。

月销金额按服务月份统计：以线路开始时间所在月份作为第一个服务月，按合同月数逐月展开；合同月销 = `销售价格 ÷ 时长（月）`，结算月销 = `结算价格 ÷ 时长（月）`，不足整月按实际月数比例计入。因此季度、半年和年付线路会在覆盖到的每个月计入月销；报告以双系列柱状图同时展示合同月销和结算月销（实际收入），图表和表格仅展示到统计基准日所在月份。

报告另提供未来 6 个月月销预测：仅纳入统计基准日在用线路，预测从下一自然月开始；假设线路到期后按当前付款周期（月、季度、半年、年）续约，合同月销和结算月销按当前月度折算金额延续，并以双系列柱状图展示。

线路平台分析中补充 UC 平台地域明细，按地域展示线路数量、带宽、带宽占比、在售/已回收拆分、合同销售额和结算金额；UC 地域占比均以 UC 平台自身汇总为分母。该明细表采用紧凑自适应布局，不展示毛利率，也不产生横向滚动条。
